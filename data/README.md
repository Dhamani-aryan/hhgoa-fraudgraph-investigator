# Data directory

`data/raw/` holds the four supplied HHGOA files plus the dataset README. It is git-ignored;
the files are never committed.

Expected contents of `data/raw/`:

| File | Approx. size | Rows |
|---|---|---|
| `README.md` | 38 KB | dataset documentation (authority #1) |
| `transactions.csv` | ~675 MB | 590,742 transactions, 397 columns |
| `identity.csv` | ~25 MB | 144,432 identity records, 41 columns |
| `closed_cases_history.csv` | ~2.6 MB | 5,565 closed investigations |
| `case_pack.csv` | 3 KB | the 20 benchmark cases |

Source: the organizers' shared dataset folder linked from the official challenge brief.

`data/prepared/` holds normalized vertex/edge files generated by `ingestion/`.
`data/cache/` holds local Parquet staging. Both are git-ignored and regenerable.

Run `python scripts/bootstrap.py` to verify the raw files are present before any other command.
